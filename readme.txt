Create product bundles for WooCommerce with fixed pricing, automatic savings, stock sync, Gutenberg block, Elementor widget and analytics.

== Description ==

**Bundle Product for WooCommerce** adds a lightweight, native "Bundle" product type to your store. Combine multiple products into one bundle with a fixed discounted price (or auto-calculated price), show customers exactly how much they save, and sell more per order.

= Why bundles? =

* Increase Average Order Value (AOV)
* Improve cross-selling and upselling
* Reduce cart abandonment with clear savings
* Simplify product packaging

= Free features =

* **Bundle product type** — a native WooCommerce product type
* **Bundle builder** — search, add, remove and drag & drop reorder simple products
* **Fixed bundle price or auto-calculation** — savings computed automatically
* **Automatic price sync** — bundle price updates when bundled product prices change
* **Stock management** — validates and reduces bundled product stock, prevents overselling
* **Product visibility** — optionally hide individual products on the bundle page
* **One-click add to cart** — the whole bundle in a single cart line
* **Cart display** — bundle contents and savings shown in cart and checkout (classic + blocks)
* **Order support** — bundled products listed in orders, emails and admin
* **Product page layouts** — List, Grid or Compact, selectable globally or per bundle
* **Design settings** — accent/savings/border colors and corner radius from the admin panel
* **Shortcode** — `[bundle id="123"]`
* **Gutenberg block** — select bundle, layout and display options
* **Elementor widget** — with style controls
* **Basic analytics** — bundles sold, revenue, savings given, top bundle
* **Import / Export** — JSON and CSV
* **SEO ready** — enriched structured data for bundles
* **Performance first** — conditional asset loading, cached queries, HPOS compatible
* **Developer friendly** — actions and filters throughout, overridable templates

= Compatibility =

* WooCommerce HPOS (High-Performance Order Storage)
* WooCommerce Cart & Checkout Blocks
* Gutenberg and Elementor
* Any well-coded theme

== Installation ==

1. Upload the plugin to `/wp-content/plugins/` or install via the Plugins screen.
2. Activate the plugin. WooCommerce must be active.
3. Go to **Products → Add New**, choose the **Bundle product** type.
4. Open the **Bundled Products** tab, add products, choose a pricing mode and publish.

== Frequently Asked Questions ==

= Which products can be bundled? =

Published simple products. Variable product support is part of the Pro roadmap.

= Does it work with the new WooCommerce cart and checkout blocks? =

Yes — bundle contents and savings display in both classic and block-based cart/checkout.

= Can I override the templates? =

Yes. Copy any file from `templates/` into `yourtheme/bundle-product-for-woocommerce/` and edit it.
